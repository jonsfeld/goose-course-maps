## Cross-source notes / discrepancies

- **Wikipedia** lists "2,478 yards, 62.6 / 110" [3]. This appears to be pre-2019 renovation data. Not used.
- **Hole19** [4] and **BlueGolf** [5] both show a "Blue" set around 2,264–2,303 yd with different per-hole numbers — these appear to be legacy/alt tees and do not match the currently posted color scheme. Not used.
- **GolfPass** [2] reports the scorecard as "18-hole" totals (4,992 / 4,632 / 3,282) because the 9 holes are played twice for a full round; per-hole yardages are identical to Greenskeeper and confirm the 9-hole values above.
- **golf.lacity.gov** official course page [6] returned HTTP 403 to automated fetchers on 2026-04-20; a human-loaded visit is recommended to re-confirm tee colors and ratings from the operator directly before publishing.
